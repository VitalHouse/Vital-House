# Vital House — modular site design

- `vital-house-logo-master.png` is the EXACT unchanged original supplied PNG; file hash must not change. It is the only logo source used across site pages and bottle labels.
- `vital-house-logo-display.png` is a transparent display-only version of the identical original contours, allowing the cream and gold backgrounds to show cleanly. The original master remains byte-for-byte unchanged. No logo redraw, retyping, proportions or shapes were changed.
- `vial-shell.svg` is a separate glass, metal, black and gold artwork WITHOUT any embedded branding.
- Each bottle uses separate HTML logo, product name, and dose layers.
- `grand-opening-lettering.png` is separate black brush lettering, unrelated to the original logo artwork.
- Website pages (`index.html`, `catalog.html`, `shop.html`, `cart.html`, `policies.html`) use shared `styles.css` and `app.js`.
- The email inquiry uses a mailto link; the visitor must press Send in their email application. There is no server backend.
- Estimated sales tax is NOT authoritative: taxability, location, and actual tax rate must be verified before transacting.
- Legal language is illustrative and should be reviewed by a qualified professional. Research-use wording does not authorize the sale of unapproved products.
- Upload all individual files from the ZIP into the root of the GitHub Pages repository, keeping `CNAME`.
